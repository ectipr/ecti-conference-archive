วันจันทร์ที่ 18 มิถุนายน 2555   
Rapid Prototyping with FiO and Rapid STM32 Blockset (จำนวน 20 ท่าน)
วิทยากร:  นาวาโท ดร. กฤษฎา แสงเพ็ชร์ส่อง

ผู้ออกแบบพัฒนาบอร์ด FiO และโปรแกรม Rapid STM32 Blockset 

โรงเรียนนายเรือ

หัวข้อการอบรม

  • แนะนำ Graphic Embedded System Development Methodology  
  • ทำความรู้จักโปรแกรม MATLAB/Simulink สำหรับติดต่อสั่งการบอร์ด FiO
  • การประยุกต์ใช้งานบอร์ด FiO ในการวัดและบันทึกค่าจากอนาลอก และดิจิตอลเซ็นเซอร์
  • การประยุกต์ใช้งาน Non-Fio Boards

ข้อมูลเพิ่มเติมสำหรับบอร์ด FiO:  www.aimagin.com/learn

วันอังคารที่ 19 มิถุนายน 2555   
Machine Vision for Industrial applications Workshop(จำนวน 20 ท่าน)
วิทยากร:  รศ.ดร.ปกรณ์ แก้วตระกูลพงษ์  มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี

หัวข้อการอบรม

  • แนะนำ และอธิบายประโยชน์ของระบบ Machine Vision
  • ตัวอย่างการใช้งานในอุตสาหกรรมต่างๆ
  • แนะนำอุปกรณ์ที่ใช้ในระบบ Machine Vision
  • แนะนำ อธิบายและสาธิตการใช้ซอฟท์แวร์ HALCON และ Tool ต่างๆของซอฟท์แวร์
  • ลงปฏิบัติ เรียนรู้วิธีการใช้ Assistant ของซอฟท์แวร์ HALCON เช่น Image Acquisition, Pattern Matching, Measurement
  • ลงปฏิบัติ ตัวอย่างการพัฒนาและการประยุกต์ใช้ระบบ Machine vision สั่งงานบนชุดสาธิต
